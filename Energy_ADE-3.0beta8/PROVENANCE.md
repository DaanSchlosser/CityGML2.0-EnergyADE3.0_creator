# Provenance: Energy ADE 3.0 (beta 8)

The contents of this directory are a vendored copy of the **CityGML Energy
Application Domain Extension (ADE) 3.0, beta 8**. The schema set under `xsd/`
is bundled so the toolkit can validate its output offline against the exact
schema it targets, without a network round-trip to a remote schema host.
